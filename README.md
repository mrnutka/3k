# game3k — เกม H5 MMORPG สามก๊ก

- `blueprint/` สำเนาพิมพ์เขียวทั้ง 6 แท็บ (ต้นฉบับแก้ได้อยู่ที่ https://claude.ai/code/artifact/a11ce7f9-f240-47bd-8e57-7a70649011e3)
- `design/economy/` งานออกแบบเศรษฐกิจฉบับเต็มแต่ละส่วน (.md) และตัวเลขสำหรับทำชีต (.json)
- `research/` งานค้นคว้าที่ตรวจแล้ว: ระบบเทรดของเกมอื่น เกมต้นแบบ เงินตราและราคายุคฮั่น ตราและสีประจำก๊ก ตัวอย่างพอร์เทรต ข้อเสนอชื่อเกมและโดเมน (`names.md`)
- `tools/econ-sim/` แบบจำลองเศรษฐกิจ 90 วัน
