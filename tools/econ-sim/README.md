# แบบจำลองเศรษฐกิจ 90 วัน

แบบจำลองรายวันของผู้เล่น 1,000 คน (ฟรีเล่นน้อย / ฟรีขยัน / ผู้เติมเงิน) ไม่มีการสุ่ม รันกี่ครั้งก็ได้ผลเท่าเดิม

- ข้อมูลตั้งต้น: ไฟล์ .json ในโฟลเดอร์นี้ (spine, npc, drops, upgrade, trade, cash, codex)
- ค่าที่ปรับรอบ 2: `sim/r2_changes.json`
- ผลลัพธ์: `sim/out/` (ตารางอยู่ใน `tables_*.md`)

วิธีรัน (ต้องมี Node.js):

    cd D:\game3k\tools\econ-sim\sim
    node sim.js --params r2_changes.json --tag ชื่อรอบ

## รอบ 3 (2026-10-01)

ใส่ข้อตัดสินของเจ้าของวันที่ 30 ก.ย. และ 1 ต.ค. (แท็บ 07 ข้อ 18–19) ค่าอยู่ใน `sim/r3_changes.json` ซึ่งซ้อนบน `r2_changes.json`:

- ศักดินาอ๋อง 1,000,000 ต่อวัน 3 อ๋องตั้งแต่วันที่ 8 · 90% เข้าทุนชิงบัลลังก์อัตโนมัติและถูกทำลายทันที จึงนับเงินเข้าแค่ 10% ที่ถึงกระเป๋า (ทุนแสดงแยกใน `days[].throne`)
- ไหมสายตราได้จากการเล่นเท่านั้น ผืนละ 5% สูงสุด 20% ต่อขั้น ลดความดีความชอบของบรรดาศักดิ์ขั้น 9–12 (ข้อสมมติ: ได้สัปดาห์ละ 1 / 2 / 1.5 / 2 ผืน สำหรับฟรีเล่นน้อย / ฟรีขยัน / ผู้เติมเงิน / วาฬ ตั้งแต่ Lv 30)
- ตายจากมอนเสีย EXP 1% ของเลเวลนั้น (ข้อสมมติ: ตายวันละ 1 / 2 / 1 / 2 ครั้ง · ผู้เติมเงินและวาฬถือบัตรตลอดชีพจึงไม่เสีย)
- โรงเตี้ยม: ม้วนกลับเมือง 0.02 × S(L) และพัก 0.01 × S(L) นับรวมในของจำเป็น (ข้อสมมติ: ฟรีเล่นน้อยวันละ 1 + 1 · ฟรีขยัน 2 + 2 · ผู้เติมเงินและวาฬใช้สิทธิ์ฟรีของบัตร และป้ายม้าเร็วหลวงฟรีวันละ 3 ใบแทนค่าม้าเร็ว)

วิธีรัน:

    cd D:\game3k\tools\econ-sim\sim
    node sim.js --r3

ได้ 6 ฉาก: `r3_main_70_22_8` (ฉากหลัก) · `r3_main_70_25_5` (สัดส่วนผู้เล่นตามแท็บหลัก) · `r3_auto3_70_22_8` (ทุกคนออโต้ผลเต็มครบวันละ 3 ชม.) · `r3_fief_only_70_22_8` (เฉพาะศักดินาใหม่) · `r3_fief_keepall_70_22_8` (ศักดินาใหม่แต่อ๋องเก็บทั้งหมด ใช้เทียบ) · `r3_inn2x_70_22_8` (ใช้โรงเตี้ยมเป็นสองเท่า) · สรุปผลอยู่ในแท็บ 07 ข้อ 20
