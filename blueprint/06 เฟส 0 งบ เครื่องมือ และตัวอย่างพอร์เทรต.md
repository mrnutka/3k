# เฟส 0: งบ เครื่องมือ และตัวอย่างพอร์เทรต

งบเฟส 0 ใช้ไม่เกิน 100 USD ทดสอบบนคอมเครื่องนี้ก่อน และพอร์เทรตใช้แนวกึ่งเหมือนจริง

## งบเฟส 0 (100 USD) และการทดสอบบนเครื่องนี้

เฟส 0 วางแผนใช้เงินราว 42 USD และเก็บสำรอง 58 USD ซื้อ Aseprite สัปดาห์แรก ส่วน PixelLab Tier 1 สมัครเดือนเดียวตอนทำฉากทดสอบ Blender, Tiled, PixiJS, ฟอนต์ และชุดท่าคนกับม้ารุ่นฟรีไม่ต้องจ่าย คอมเครื่องนี้รัน Blender และ WebGL2 ได้ แต่ไม่คุ้มที่จะรัน AI ภาพหรือ AI 3D ในเครื่อง มือถือทดสอบราว 3,700 บาท (≈111 USD) อยู่นอกงบนี้ ให้ซื้อเมื่อฉากผ่านเกณฑ์บนคอมแล้ว

ราคาตรวจจากหน้าทางการเมื่อ 28 ก.ย. 2026 ใช้อัตรา 1 USD ≈ 33.4 บาท

### แผนทดสอบบนคอมเครื่องนี้

ทดสอบใน Chrome บนคอมนี้ก่อน โดยจำลองจอมือถือและ throttle CPU กับเครือข่าย แต่ CPU throttle ของ DevTools ไม่ชะลอ GPU ([Chrome](https://developer.chrome.com/blog/devtools-grounded-real-world)) ผลบนคอมจึงกรองได้แค่งานฝั่ง CPU และ DOM ภาระ GPU ต้องนับด้วย overlay แล้วยืนยันบนมือถือจริง

**อุปกรณ์จำลอง** (DevTools > Settings > Devices > Add custom device เลือก Mobile) ช่องกว้างยาวเป็น CSS px ถ้าใส่ 1640×720 กับ DPR 2 จะได้ canvas 3280×1440 ซึ่งผิด ต้องใส่ 820×360

| Redmi 14C ในแอป LINE | 820×304 | 2 | 1640×608 | แถบบนของเบราว์เซอร์ในแอป |

**ขั้นตอน**

1. เปิด Chrome โปรไฟล์ทดสอบที่ไม่มีส่วนขยาย: `"C:\Program Files\Google\Chrome\Application\chrome.exe" --user-data-dir=C:\game3k-cache\chrome-test --no-first-run http://localhost:5173/?debug=1`
2. ไปที่ Performance > CPU throttling > Calibrate เพื่อสร้างค่า low-tier และ mid-tier mobile ของเครื่องนี้ (มีตั้งแต่ Chrome 134 [Throttling](https://developer.chrome.com/docs/devtools/settings/throttling)) ถ้ายังไม่ calibrate ให้ใช้ 4× และ 6×
3. Network: ติ๊ก Disable cache ใช้ Fast 4G (ราว 9 Mbps, 165 ms) เป็นเกณฑ์ผ่าน และใช้ Slow 4G (ราว 1.4 Mbps, 562 ms) ดูว่าหน้าไม่ค้าง ([DebugBear](https://www.debugbear.com/blog/chrome-devtools-network-throttling)) ที่ Slow 4G ไฟล์ 8 MB ใช้ราว 46 วิ
4. เล่นฉากละ 60 วิ แล้วเก็บ trace 20 วิใน Performance
5. ให้ Claude เขียน `tools/bench.mjs` ด้วย Playwright + CDP (`Emulation.setDeviceMetricsOverride`, `Emulation.setCPUThrottlingRate`, `Network.emulateNetworkConditions`) รันซ้ำทุกบิลด์แล้วบันทึก p50/p95 ลง CSV
6. ถ้าอยากรู้เพดานจริง ให้เปิดอีกโปรไฟล์ด้วย `--disable-gpu-vsync --disable-frame-rate-limit` ค่านี้ใช้ดูเพดาน ไม่ใช่เกณฑ์ผ่าน

**ตรวจ WebGL2 (หน้า `?debug=1`)**

- `getContext('webgl2')` ต้องสำเร็จ และแสดงชื่อ GPU จาก `WEBGL_debug_renderer_info` บนจอ debug
- ถ้าสร้าง context ไม่ได้ต้องขึ้นข้อความภาษาไทย ทดสอบด้วยโปรไฟล์ที่เปิด `--disable-gpu` เพราะ Chromium เลิก fallback ไป SwiftShader อัตโนมัติ ([Chromium](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/docs/gpu/swiftshader.md))
- atlas ไม่เกิน 2048×2048 ต่อหน้าตามข้อ 10 ห้ามตั้งตามค่า 16384 ของเครื่องนี้ ในทางปฏิบัติทุกระบบรองรับอย่างน้อย 4096 ([MDN](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/WebGL_best_practices))
- อัปโหลด R8 โดยตั้ง `UNPACK_COLORSPACE_CONVERSION_WEBGL = NONE` ไม่ premultiply แล้วอ่านกลับเทียบต้นฉบับ ต้องตรง 100% (ข้อ 2.1 และ 10)
- ทำ context lost แล้ว restore ด้วย `WEBGL_lose_context` เกมต้องกลับมาเล่นต่อได้
- ตั้ง PixiJS `preference: 'webgl'` และเขียน `renderer.type` ลง log
- Redmi 14C และ 15C มีจอ 120 Hz จึงจำกัด ticker ที่ 60 fps

```text
Image 1 is a STYLE reference only: match its brushwork, lighting and background, not its person or costume. Image 2 is a colour card: use only these colours for the accents. **ขั้นตอนทำซ้ำให้เข้าชุด**
```

1. เริ่มพอร์เทรตต้นแบบ 1 ตัว (แนะนำโจโฉ) สร้าง 4 แบบด้วย STYLE + บล็อกขุนพล + ช่อง 2–6 แล้วคนเลือก 1 แบบ
2. แก้ต่อในบทสนทนาเดิมครั้งละ 1 เรื่อง ด้วยประโยค "Keep everything else exactly the same; change only …" ไม่เกินราว 6 รอบ
3. เกลามือใน Krita (ฟรี): หน้า มือ ลายเกราะ และคอเสื้อ
4. ภาพที่อนุมัติเป็นภาพสไตล์ช่อง 1 ของขุนพลอีก 3 ตัว เปิดบทสนทนาใหม่ต่อขุนพล เพื่อไม่ให้หน้าเดิมปน
5. วาง 4 ภาพเรียงกัน ตัวไหนหลุดชุด ให้แนบอีก 3 ตัวเป็นภาพสไตล์ (ครบโควตา 3) แล้วสร้างใหม่
6. ทำแผ่นหน้าตัวละคร สีหน้า และคัตอิน ด้วยพรอมต์แก้ไขด้านล่าง Google DeepMind ระบุว่าการคงหน้าคน "อาจไม่ถูกทุกครั้ง" จึงตรวจด้วยตาทุกภาพ
7. บันทึกพรอมต์ ภาพอ้างอิง วันที่ รุ่นโมเดล และค่าใช้จ่ายลง `asset_license.csv`

```text
EXPRESSION EDIT: Use the attached portrait as the only reference. Keep the same man, face shape, beard, costume, colours, lighting, background, framing and brushwork exactly as they are. Change only his expression to controlled battle anger: brows drawn down, eyes narrowed, jaw set, lips slightly parted.

IDENTITY SHEET: Using the attached portrait, paint a reference sheet of the same man in the same style on the same plain rice-paper background: three head-and-shoulders views side by side — front, three-quarter and side profile — neutral expression, even soft light, same headwear and beard, no text or labels.

CUT-IN: Using the attached portrait, paint an extreme close-up of the same man's face from brow to chin as a wide horizontal band (21:9), eyes on the upper-third line, same lighting, brushwork and colours, plain dark ink-wash background, no text.
```

- [ ] คนตรวจอย่างน้อย 1 คนไม่ใช่คนทำภาพ
